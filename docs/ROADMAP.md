# Roadmap

Build and test modules in this order:

1. Resource group and common tags
2. Storage account (secure defaults, private access options)
3. Virtual network, subnet, and NSG
4. Log Analytics workspace and diagnostic settings
5. Key Vault and managed identity
6. Linux VM
7. App Service / Function App
8. Azure SQL and PostgreSQL Flexible Server
9. Private endpoint and private DNS
10. Container Registry and AKS
11. Azure Databricks workspace
12. Reusable monitoring alerts and action groups

For each resource family, add a small example and document required Azure permissions, cost considerations, and security trade-offs.
